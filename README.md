# Für Elise ❄︎

Снег на рабочем столе Mac. Снежинки падают поверх всего, оседают на окнах и Dock,
сугробы можно смахнуть курсором, а из снега — скатать снежки и слепить снеговика.

## Возможности

- Снег копится на верхних краях окон, на Dock и внизу экрана, осыпается с краёв и сползает по склонам.
- Сдвинули или закрыли окно — снег с него падает вниз.
- Клики проходят сквозь снег: работать можно как обычно.
- **Варежка** — смахнуть снег курсором (он разлетается). **Лопата** — убрать всё с окна одним касанием.
- **Снежки**: зажмите ⌥ и ведите курсором по снегу. Отпустите ⌥ — снежок упадёт.
  Три снежка друг на друге — снеговик.
- **Трактор** 🚜 выезжает и чистит низ экрана: сгребает снег отвалом и выбрасывает его вверх,
  сбивает снежки. Вызывается из меню (⌘T) или сам, когда наметёт сугроб.
- **Гирлянда** под строкой меню: разноцветная или тёплая белая; мерцание, бегущий огонь или ровный свет.
- **Без сугробов** — переключатель «Копить сугробы»: снег просто падает сквозь экран и нигде не копится.
- Снегопад: лёгкий, ровный, метель. Ветер влево/вправо. Автозапуск.
- Все настройки — в панели по клику на ❄︎ в строке меню.
- **Пауза** замораживает снег на экране, **«Выключить снег»** убирает его полностью
  и останавливает рендеринг (ноль нагрузки), иконка в строке меню остаётся.
- Несколько мониторов. На рабочем столе полноэкранного приложения снега нет,
  а когда вы возвращаетесь, всё лежит как было.
- Бережёт батарею: 30 fps, пока снег просто падает, и 60 fps — когда вы с ним играете;
  в режиме энергосбережения и при нагреве снега меньше.

Требования: macOS 13 Ventura и новее, Apple Silicon или Intel.

## Установка

1. Скачайте `FurElise.dmg` со страницы [Releases](../../releases) и перетащите Für Elise в «Программы».
2. Приложение не подписано сертификатом Apple Developer, поэтому при первом запуске macOS его заблокирует.
   Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.
   Или одной командой в Терминале:
   ```sh
   xattr -dr com.apple.quarantine "/Applications/Für Elise.app"
   ```
3. Снег на Dock: в панели ❄︎ нажмите **«Дать доступ»** внизу и включите Für Elise в
   **Конфиденциальность и безопасность → Универсальный доступ**. Это нужно только чтобы узнать
   размер панели Dock — содержимое окон приложение не читает.
   После обновления приложения доступ, возможно, придётся выдать заново.

## Сборка из исходников

Нужны только Command Line Tools (`xcode-select --install`), Xcode не обязателен.

Для локальной разработки один раз выполните `./scripts/setup-signing.sh` — он создаёт постоянный
самоподписанный сертификат в `.signing/`, и доступ к Dock не слетает после каждой пересборки.
Ключ подписи обновлений Sparkle тоже лежит в `.signing/` (`sparkle_private.key`, `sparkle_public.key`;
публичный записан в `Resources/Info.plist` → `SUPublicEDKey`).

```sh
./build.sh          # → build/Für Elise.app, build/FurElise.zip, build/FurElise.dmg
open "build/Für Elise.app"
```

Иконка генерируется скриптом `swift scripts/make-icon.swift` (результат уже лежит в `Resources/AppIcon.icns`).

## Обновления

Приложение обновляется само (через [Sparkle](https://sparkle-project.org)): раз в день проверяет
ленту `appcast.xml` из последнего релиза и предлагает установить новую версию.
Проверить вручную — кнопка «Обновления» в панели ❄︎.

## Релиз

```sh
git tag -a v1.2.0 -m "Что нового: строка — пункт списка"
git push origin v1.2.0
```

GitHub Actions соберёт приложение, подпишет его и прикрепит к релизу `FurElise.dmg`, `FurElise.zip`
и `appcast.xml` — после этого все установленные копии увидят обновление.
Текст тега попадёт в описание релиза и в окно обновления.

Секреты репозитория (Settings → Secrets and variables → Actions):

| Секрет | Что это |
|---|---|
| `SIGNING_P12_BASE64` | `base64 -i .signing/cert.p12` — сертификат подписи (тот же, что локально) |
| `SPARKLE_PRIVATE_KEY` | `.signing/sparkle_private.key` — ключ подписи обновлений |

Без `SPARKLE_PRIVATE_KEY` обновления не выпустить: приложения отвергнут неподписанную ленту.
Папку `.signing/` берегите и не публикуйте — в ней приватные ключи.

## Автоматизация

Вызвать трактор из скрипта или Shortcuts:

```sh
swift -e 'import Foundation; DistributedNotificationCenter.default().postNotificationName(.init("app.snowfall.FurElise.tractor"), object: nil, userInfo: nil, deliverImmediately: true)'
```

## Устройство

| Файл | Что делает |
|---|---|
| `Sources/FurElise/main.swift` | Приложение, значок в строке меню, прозрачные окна-оверлеи на каждом экране |
| `Sources/FurElise/Panel.swift` | Панель настроек на SwiftUI |
| `Sources/FurElise/Garland.swift` | Гирлянда |
| `Sources/FurElise/SnowScene.swift` | SpriteKit-сцена: снегопад, сугробы, курсор, снежки |
| `Sources/FurElise/Model.swift` | Сугроб (карта высот по столбикам), частица, снежок |
| `Sources/FurElise/WindowTracker.swift` | Границы окон через `CGWindowList` (без доступа к содержимому) |
| `Sources/FurElise/DockTracker.swift` | Границы Dock через Accessibility API |
| `Sources/FurElise/SpaceTracker.swift` | Определяет полноэкранные Space (закрытый, но стабильный `CGSCopyManagedDisplaySpaces`) |
| `Sources/FurElise/Tractor.swift` | Снегоуборочный трактор |
| `Sources/FurElise/Settings.swift` | Настройки в `UserDefaults` |
